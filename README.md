## 📊 Data Cleaning & Visualization Project

A Python-based data analysis project that demonstrates the complete workflow of cleaning raw data and creating meaningful visualizations using popular data science libraries.

## 🚀 Project Overview

This project focuses on:
- Importing and exploring raw datasets
- Handling missing values and duplicate records
- Cleaning and transforming data
- Exporting the cleaned dataset
- Creating visualizations to identify trends and insights

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn

## 📁 Project Structure

```
Data-Cleaning-Visualization-Project/
│── data.csv                 # Original dataset
│── cleaned_data.csv         # Cleaned dataset
│── cleaning.py              # Data cleaning and visualization script
│── requirements.txt         # Required Python libraries
│── README.md                # Project documentation
```

## ⚙️ Installation

1. Clone this repository

```bash
git clone https://github.com/bendaleheramb05/Data-Cleaning-Visualization-Project.git
```

2. Move into the project directory

```bash
cd Data-Cleaning-Visualization-Project
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

## ▶️ Run the Project

Execute the Python script:

```bash
python cleaning.py
```

## 📈 Features

- Data Cleaning
  - Remove missing values
  - Remove duplicate records
  - Handle inconsistent data

- Data Visualization
  - Charts using Matplotlib
  - Statistical plots using Seaborn

- Export cleaned dataset as:

```
cleaned_data.csv
```
